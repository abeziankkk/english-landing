# Лендинг репетитора английского

Одностраничный сайт для записи на уроки английского для взрослых. Сделан на чистых HTML и CSS, без фреймворков и сборки.

Это демо-проект с вымышленными данными. Кнопки записи ведут на Telegram-бота.

## Как открыть сайт

1. Откройте папку проекта.
2. Дважды кликните по файлу `index.html`.
3. Сайт откроется в браузере.

## Где менять тексты

Все тексты страницы лежат в `index.html`:

- шапка — внутри блока `<header class="hero">`;
- «Обо мне» — секция с `id="about"`;
- карточки «Что ты получишь» — секция с `id="benefits"`;
- цены — секция с `id="prices"`;
- отзывы — секция с `id="reviews"`;
- контакты — блок `<footer class="footer">`.

Внешний вид (цвета, отступы, сетка) меняется в `style.css`. Акцентный цвет задан в начале файла в переменной `--accent`.
